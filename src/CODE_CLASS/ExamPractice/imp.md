## Conceptual Questions
1. **Explain LIFO and FIFO.** How do these principles define the behavior of Stacks and Queues?
2. **Stack vs. Queue:** List at least four differences between a Stack and a Queue.
3. **What is Stack Overflow and Stack Underflow?** When do these conditions occur in an array-based implementation?
4. **Circular Queue:** Why is a circular queue preferred over a simple linear queue when using an array?
5. **Real-world Applications:** Give three real-world examples each for the use of a Stack and a Queue.

---

## Implementation Tasks
1. **Stack using Array:** Implement a stack with `push()`, `pop()`, `peek()`, and `isEmpty()` operations.
2. **Queue using Array:** Implement a linear queue with `enqueue()`, `dequeue()`, and `display()` operations.
3. **Circular Queue:** Implement a circular queue to handle the "wasted space" problem in linear queues.
4. **Stack using Linked List:** Implement a stack where each element is a node in a linked list.
5. **Queue using Linked List:** Implement a queue using linked list nodes, maintaining both `front` and `rear` pointers.

## Algorithmic Problems (Stack)
1. **Reverse a String:** Use a stack to reverse a given string.
2. **Balanced Parentheses:** Write a program to check if an expression (e.g., `{[()]}`) is balanced using a stack.
3. **Infix to Postfix:** Convert a mathematical expression from infix notation to postfix notation.
4. **Evaluate Postfix:** Write a program to evaluate a given postfix expression (e.g., `231*+9-`).
5. **Implement Stack using Two Queues:** How can you simulate stack behavior using only queue operations?

---

## Algorithmic Problems (Queue)
1. **Implement Queue using Two Stacks:** How can you simulate queue behavior using only stack operations?
2. **Reverse a Queue:** Write a program to reverse all elements in a queue using a stack.
3. **Priority Queue:** What is a priority queue, and how does it differ from a standard queue?
4. **Deque (Double-Ended Queue):** Implement a Deque where insertion and deletion can happen at both ends.
5. **Generate Binary Numbers:** Use a queue to generate binary numbers from 1 to N.
